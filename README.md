# CS Assignment Tracker

A modern, intuitive platform built for Computer Science cohorts to effortlessly track and manage their coursework.

## The Vision

This project was built to bring together the best of two worlds. It takes the simplicity and ease-of-use of a central, shared Google Sheet, while delivering a robust web app experience that goes above and beyond a traditional spreadsheet. 

By prioritizing a clean, visually appealing user interface, the tracker aims to reduce cognitive load and make academic planning feel rewarding rather than overwhelming.

## Built For The Cohort
  
**For Admins:**
We designed the administrative experience to be as frictionless as possible. Adding new tasks or updating existing deadlines requires minimal clicks, ensuring course coordinators can distribute assignment information swiftly without wrestling with clunky management systems.

**For Students:**
The dashboard serves as a personalized hub for academic progress. It empowers students to see upcoming requirements at a glance and satisfyingly "tick off" completed coursework, providing immediate visual feedback on their journey through the semester.

## Key Features

- **Personalized Progress Tracking:** Students can seamlessly mark assignments as done.
- **Admin Dashboard:** Effortless task creation with easy-to-use forms for managing deadlines and submission URLs.
- **Chronological Sorting:** Assignments are intuitively ordered by due date so the most pressing tasks are highlighted first.
- **Glassmorphism Aesthetic:** A modern, elegant web interface designed to delight users.

## Tech Stack

- **Frontend:** Angular, HTML, CSS
- **Backend:** Spring Boot (Java)
- **Deployment:** GitHub Pages (Frontend) & Hugging Face Spaces (Backend)
